Política de Privacidade

1. Coleta de Informações

A SecuHouse coleta apenas as informações necessárias para fornecer nossos serviços de segurança residencial:

  • Dados de registro do dispositivo
  • Informações de conta do usuário
  • Dados de uso do sistema
  • Gravações de câmera (quando ativadas)

2. Uso das Informações

Utilizamos suas informações para:

  • Fornecer serviços de monitoramento
  • Melhorar a segurança do sistema
  • Enviar alertas e notificações
  • Manter o histórico de eventos

3. Proteção de Dados

Implementamos medidas rigorosas de segurança para proteger suas informações:

  • Criptografia de ponta a ponta
  • Autenticação de dois fatores
  • Backups seguros
  • Monitoramento constante
